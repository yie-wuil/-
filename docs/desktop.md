# 时光轴 - 日程管理  目标  番茄钟  任务提醒

纯本地的日程管理工具：目标管理 + 每日时间安排 + 任务计划 + 番茄钟 + 提醒音乐 + 附件文档。
所有数据只保存在你自己的电脑上，不联网、不上传。

---

## 一、怎么打开

**方式 1：桌面程序（推荐）**
双击 `dist\时光轴-win32-x64\时光轴.exe`，或桌面上的「时光轴」快捷方式。
免安装绿色版，整个 `时光轴-win32-x64` 文件夹可拷到任意位置，删掉即卸载。

**方式 2：网页版**  双击 `index.html` 用浏览器打开（容量有差异，见文末）

**方式 3：开发模式**  先 `pnpm install`，再 `pnpm start`

## 二、目标（阶段性目标）

顶部视图切换里的第 5 个标签「**目标**」（快捷键 `5`）。

**目标是什么**
一个带终点和阶段的长线任务，比如「读完 12 本书」「3 个月减重 5 公斤」「完成项目上线」。
每天的任务挂到目标下，完成的每一天都会累积成目标的进度。

**怎么用**
1. 点右上角「**+ 新建目标**」，填写：
   - 目标名称、描述
   - **目标值 + 单位**（如 12 本 / 100 次 / 50 小时）
   - 起止日期
2. 在任务编辑窗口里，把任务设成「**所属目标**」，并填「**每完成一次累加**」（默认 1）
   - 例如目标「读完 12 本书」，任务「读书 30 分钟」每次完成累加 1
   - 也可以设成 0.5、30 这种，用来累加页数、分钟数
3. 每完成一次任务，目标进度就自动增加；重复任务按**实际完成的次数**累加
4. 目标卡片上会显示进度条、`已完成 / 目标值`、百分比、剩余天数、关联任务数

**阶段里程碑**
给目标加若干阶段（如「第一阶段 3」「第二阶段 8」），进度达到设定值时**自动点亮**，
距离达标还差 20% 以内会高亮提示，让你清楚知道现在走到哪一步了。

**手动补充进度**
有些目标不方便拆成任务（如「减重 5 公斤」），可以在目标里直接填「手动补充进度」。

**其他**
- 目标状态：进行中 / 已完成 / 已归档（进度达标会自动显示「已达成」）
- 删除目标不会删除任务，只解除关联（5 秒内可撤销）

## 三、每日时间安排（作息模板）

专门用来"把一天排好"。入口：日视图顶部「调整每日安排」。

1. 内置 **工作日 / 周末** 两套模板，可直接改成你自己的
2. 逐条编辑时间块：`开始 - 结束 + 做什么 + 分类 + 优先级`，可增删
3. 选日期后点「应用到该日期」，模板即变成那天的任务
   - 默认**追加并自动去重**（同标题+同开始时间不会重复添加）
   - 勾选「覆盖该日已有安排」则先清空当天再写入
4. 「把某天存为模板」可把手工排好的一天存成新模板复用

日视图顶部会显示 `任务数 / 已安排时长 / 完成进度`；当前正在进行的任务会加描边和「进行中」标签。

## 四、任务时间结束提醒（播音乐）

**入口**：日视图顶部的「**提醒音乐**」按钮（也可从「数据」菜单进入）。
按钮上的小圆点是**绿色**时表示已开启，鼠标悬停可看到当前用的是哪首音乐。

- **任务时间结束时播放音乐**：任务结束时间一到自动播放
- **自定义音乐**：点「选择」上传 mp3 / wav / m4a / ogg，保存在本机；不设置则用内置提示音
- **音量** 0~100% 可调，「试听」立刻听效果；提醒弹出时点「停止音乐」可中断
- 可同时开启**系统通知**

## 五、任务附件文档

- 任务编辑窗口底部「附件文档」「+ 添加文件」，可一次选多个，类型不限
- 点「打开」查看或下载到本机，点右侧删除按钮移除，每任务最多 10 个
- 删除任务时附件一并清理（5 秒内撤销则不会丢）

---

## 六、任务管理

- **四种视图**：日（24 小时时间轴）/ 周（七日看板）/ 月（完整日历）/ 列表（按天分组）
- 任务属性：标题、日期、起止时间、全天、优先级、分类、备注、附件、所属目标
- **重复任务**：每天 / 工作日 / 每周 / 每月 / 每年，可设截止日；支持"按次完成"
- **拖动操作**：时间轴上拖任务块改时间、拖边缘改时长；拖卡片到日历格子改日期
- 点击时间轴空白处，直接按那个时刻新建任务

## 七、番茄钟

- 25 分钟专注 / 5 分钟短休息 / 15 分钟长休息，每 4 个番茄进入长休息（侧栏「设置」可调）
- 圆环倒计时，运行时右下角有迷你计时器，切换视图不中断
- 可**关联当天任务**：每完成一个番茄给该任务记 1 个（列表显示「番茄 N」）

## 八、其他

- 侧栏迷你月历、今日完成进度、本周统计、逾期计数
- 搜索 + 分类 + 优先级 + 完成状态筛选
- 深色 / 浅色主题；桌面通知；删除可撤销

## 九、数据与备份

- 数据保存在本机，关闭不丢失，但不会同步到其他电脑
- 桌面版数据位置：`%APPDATA%\时光轴`（想彻底重置就删掉该文件夹）
- **备份请用「数据」菜单里的「导出数据（JSON）」**，在新机器「导入数据」即可（合并式，不会清空现有数据）
- 「导出日历（ICS）」可把任务导入手机日历 / Outlook / Google 日历

**关于附件与音乐**：文件本体体积较大，单独存放在本地数据库，**不包含在 JSON 导出中**；
换电脑时任务、目标、作息模板会跟着走，附件和自定义音乐需要重新添加。

**容量说明**
| | 桌面版 | 网页版 |
|---|---|---|
| 附件与音乐存储 | 本地数据库（IndexedDB） | 浏览器 localStorage（自动降级） |
| 单个文件上限 | 12 MB | 约 1 MB |

桌面版通过 `app://` 自定义协议加载，属于安全上下文，存储空间充足。

## 十、目录说明

```
index.html              程序本体（单文件，桌面版与网页版共用）
main.js                 Electron 主进程（自定义协议 / 单实例 / 自动播放策略）
pack.js                 一键打包脚本
build\icon.ico          应用图标
dist\时光轴-win32-x64\   打包好的桌面程序（免安装）
```

## 十一、重新打包

```
pnpm install
pnpm dist
```

`pack.js` 会自动使用国内镜像下载 Electron，并在打包后精简语言包（约省 40 MB）。
